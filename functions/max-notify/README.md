# max-notify — пересылка заявок с сайта в MAX

Маленькая Yandex Cloud Function: принимает данные формы с сайта и отправляет их вам в MAX через официальный MAX Bot API.

## Шаг 1. Получить токен бота (в приложении MAX)

1. В MAX найдите **@MasterBot**.
2. Нажмите «Начать», следуйте подсказкам, придумайте имя боту.
3. MasterBot пришлёт **токен** — скопируйте и сохраните его.
4. Напишите новому боту любое сообщение («привет») — без этого бот не сможет писать вам в ответ.

## Шаг 2. Узнать свой `user_id`

Проще всего — отправить боту сообщение и посмотреть входящие обновления через API (это можно сделать один раз вручную, например через `curl` или Postman, методом получения обновлений — если понадобится помощь на этом шаге, попросите).

## Шаг 3. Развернуть функцию в Yandex Cloud

1. Зайдите в [console.cloud.yandex.ru](https://console.cloud.yandex.ru) → **Cloud Functions** → «Создать функцию».
2. Среда выполнения: **Node.js 18** (или новее).
3. Загрузите файл `index.js` из этой папки (или скопируйте его содержимое).
4. Точка входа (entrypoint): `index.handler`.
5. В разделе **Переменные окружения** добавьте:
   - `MAX_BOT_TOKEN` — токен из Шага 1
   - `MAX_USER_ID` — ваш user_id из Шага 2
6. В настройках доступа включите **публичный вызов по HTTP** (без IAM-токена) — иначе сайт не сможет достучаться до функции напрямую с браузера.
7. Сохраните — Yandex Cloud выдаст публичный URL вида `https://functions.yandexcloud.net/<id>`.

## Шаг 4. Подключить к сайту

Пришлите мне этот URL — я подставлю его в `src/components/FaqCta.astro` вместо плейсхолдера `MAX_NOTIFY_FUNCTION_URL` и пересоберу сайт.

## Тест без сайта (опционально)

```bash
curl -X POST "https://functions.yandexcloud.net/<ваш-id>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","contact":"test@example.com","project-type":"Сайт"}'
```
Ожидаемый ответ: `{"ok":true}`, и сообщение должно прийти в MAX.
