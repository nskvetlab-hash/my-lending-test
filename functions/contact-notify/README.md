# contact-notify — пересылка заявок с сайта на почту

Маленькая Yandex Cloud Function: принимает данные формы с сайта и отправляет их на почту по SMTP (через вашу же почту mail.ru).

## Шаг 1. Получить пароль приложения в Mail.ru

Обычный пароль от почты для SMTP не подойдёт — нужен отдельный «пароль для внешних приложений».
Важно: это находится в настройках самой **Почты** (e.mail.ru), а НЕ в настройках аккаунта (id.mail.ru) — это разные страницы.

1. Откройте [e.mail.ru](https://e.mail.ru) → внизу слева иконка **шестерёнки** → «Все настройки».
2. Вкладка **«Безопасность»**.
3. В разделе **«Внешние сервисы»** включите переключатель **«Доступ к почте по IMAP, POP и SMTP»** — без этого SMTP не заработает, даже с паролем приложения.
4. Там же найдите **«Пароли для внешних приложений»** → «Создать» → название (например, «Сайт — заявки») → скопируйте выданный пароль.
5. Это и есть `SMTP_PASSWORD` — не обычный пароль от почты.

## Шаг 2. Развернуть функцию в Yandex Cloud

1. Зайдите в [console.cloud.yandex.ru](https://console.cloud.yandex.ru) → **Cloud Functions** → «Создать функцию».
2. Среда выполнения: **Node.js 18** (или новее).
3. Загрузите содержимое этой папки целиком (`index.js` + `package.json`) — Yandex Cloud сам установит `nodemailer` из `package.json` при сборке.
4. Точка входа (entrypoint): `index.handler`.
5. В разделе **Переменные окружения** добавьте:
   - `SMTP_USER` — ваш email, например `q.m.nmvl@mail.ru`
   - `SMTP_PASSWORD` — пароль приложения из Шага 1
   - `NOTIFY_TO` — куда слать заявки (можно не задавать — по умолчанию `q.m.nmvl@mail.ru`)
6. В настройках доступа включите **публичный вызов по HTTP** (без IAM-токена) — иначе сайт не сможет достучаться до функции напрямую с браузера.
7. Сохраните — Yandex Cloud выдаст публичный URL вида `https://functions.yandexcloud.net/<id>`.

## Шаг 3. Подключить к сайту

Пришлите мне этот URL — я подставлю его в `src/components/FaqCta.astro` вместо плейсхолдера `MAX_NOTIFY_FUNCTION_URL` и пересоберу сайт.

## Тест без сайта (опционально)

```bash
curl -X POST "https://functions.yandexcloud.net/<ваш-id>" \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","contact":"test@example.com","project-type":"Сайт"}'
```
Ожидаемый ответ: `{"ok":true}`, письмо должно прийти на `NOTIFY_TO`.
