# Карта проекта (граф знаний)

Сгенерировано `/graphify` 2026-09-17. Полный граф и живые запросы — в `graphify-out/` (`graph.html`, `GRAPH_REPORT.md`, `graph.json`). Обновить после значимых изменений: `/graphify --update`.

## Из чего состоит проект

- **research.md** — исследование конкурентов, структуры лендингов, трендов 2026, экспертный аудит (3 роли)
- **brief.md** — ТЗ: 7 секций лендинга, 3 варианта дизайна, обязательные элементы
- **docs/superpowers/plans/2026-09-16-landing-page-astro.md** — план реализации на Astro (14 задач)
- **.claude/rules/typography-audit.md** — правило аудита русской типографики (самостоятельный контур, слабо связан с остальным)
- **.worktrees/landing-page-astro/src/** — сама реализация (Astro-компоненты, данные, функция уведомлений)

## Как читать эту карту

Каждая секция brief.md напрямую прослеживается до конкретного `.astro`-компонента (EXTRACTED-связи, не догадки). Дизайн-решения в коде (цвета, шрифты, анимации) прослеживаются обратно до конкретных пунктов research.md. Правило типографики — единственный слабо связанный островок (это отдельный, самостоятельно применяемый процесс, не часть основного потока brief→plan→code).

Для конкретных вопросов используй `graphify query "<вопрос>"` по `graphify-out/graph.json` — не обязательно читать весь GRAPH_REPORT.md целиком.
