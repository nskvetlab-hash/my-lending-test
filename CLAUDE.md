# Инструкции для Claude Code

- В начале каждой новой сессии прочитай `.knowledge-graph.md` — это краткая карта проекта (ключевые файлы, как они связаны, откуда что взялось). Полный граф и запросы к нему — в `graphify-out/`.
- Также прочитай `STATUS.md` — там памятка (хостинг, аккаунты, почта для уведомлений) и план оставшихся задач по проекту. Обновляй его по мере выполнения пунктов из плана.
- При добавлении новых файлов или изменении архитектуры — перезапускай `/graphify` из корневой папки проекта повторно, раз в несколько дней или после крупных изменений, чтобы карта не устаревала.
